# Hello, World

Assignment 01 for Design for Generative AI (Columbia, Fall 2026). A hello-world app, deployed end to end: local build, GitHub, Vercel.

## Stack

- Next.js 16 (App Router)
- Tailwind CSS v4
- Motion for React
- lucide-react for icons

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run start
```
